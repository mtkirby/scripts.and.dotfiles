# scripts.and.dotfiles

A small collection of personal utility scripts and dotfiles, published publicly because they may be useful to other people, but kept intentionally rough and unpolished.

These are not a formal toolchain or a supported package. They are mostly scripts I wrote to automate things I was doing repeatedly on my own machines: media cleanup, audiobook packaging, subtitle generation, and a few misc shell conveniences.

Not officially published.  Definitely not polished.
